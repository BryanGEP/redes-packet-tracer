# Conmutación y Enrutamiento de Redes de Datos

Prácticas y actividades de la materia **Conmutación y Enrutamiento de Redes de Datos**, desarrolladas principalmente con **Cisco Packet Tracer**.

Instituto Tecnológico de Jiquilpan (TecNM) — Ingeniería en Sistemas Computacionales.

## Contenido

- Archivos de simulación de **Cisco Packet Tracer** (`.pkt` / `.pka`): prácticas de VLANs, troncales, enrutamiento y configuración de equipos.
- **Documentos de comandos** (`.txt`) con los comandos usados en cada práctica.
- **Tablas de subneteo** (`.xlsx`): VLSM y máscaras wildcard.

## Tecnologías

- Cisco Packet Tracer
- CLI de Cisco IOS
